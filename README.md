Sales Performance Analysis – Excel Project

📌 Project Overview

This project is an Excel-based Sales Performance Analysis created to understand sales, profit, customer segments, shipping methods, categories, and regional performance.

The project takes raw sales data, cleans and organizes it, performs basic analysis using Excel formulas, and presents the key findings through a Sales Performance Dashboard.

📂 Workbook Structure

The workbook contains the following sheets:

1. Raw Data

Contains the original sales dataset with information such as:

* Ship Mode
* Segment
* Country
* City
* State
* Postal Code
* Region
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit

2. Cleaned Data

Contains the cleaned and organized version of the raw dataset. This sheet is used as the main source for further calculations and analysis.

3. Sales Report

Provides summary statistics and overall sales performance, including:

* Total Sales
* Total Profit
* Average Sales
* Other key performance metrics

4. Basic Analysis

Provides category-wise and region-wise analysis using Excel formulas such as:

* SUMIF
* COUNTIF
* AVERAGE
* SUM

The analysis focuses on sales, profit, number of orders, and profit margins.

5. Dashboard

A visual Sales Performance Dashboard that summarizes important business insights using tables, charts, and key observations.

🎯 Objectives

The main objectives of this project are:

* Analyze overall sales and profitability.
* Compare different product categories.
* Understand regional sales performance.
* Identify customer and shipping trends.
* Calculate profit margins.
* Present important findings through an easy-to-understand dashboard.
* Practice Excel data cleaning, formulas, analysis, and dashboard creation.

🔍 Key Insights

Based on the dashboard analysis:

* Technology generated the highest sales and profit among the categories.
* Standard Class was the most commonly used shipping method.
* The West Region showed strong sales and profit performance.
* Consumers contributed significantly to overall sales.
